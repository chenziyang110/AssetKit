# AssetKit 1.1.0

Low-context local asset workflows. The existing v1 assetctl interface and schema-1 records remain compatible; the shorter agent interface is additive.

## Agent interface

- Bootstrap generates `python .assets/ak.py`: checked `find`, direct `get`, minimal `put`, boundary `check`, and pageable `receipt` details.
- Top-three checked candidates consolidate discovery and resolve calls. Short references use collision-checked stable ID prefixes, not session handles.
- Compact UTF-8 byte budgets apply to final JSON. Constraints stay intact or the response fails closed; context savings never imply weaker authorization.
- Single writes acknowledge ref/revision/status; batches summarize counts and indexed failures. Complete receipts live locally; stdin JSONL avoids a temporary manifest-writing step.
- Shorten idle routing, activated instructions and per-call command paths. Advanced references load only for the relevant exception.

## Correctness fixes

Timestamp-only changes are hashed when necessary and retain unchanged authoritative cards, revisions and reviews. Current local signatures are stored in a rebuildable hash-evidence cache. Explicit hash mode bypasses it. Declared cross-card dependencies are verified with cycle, depth, node and file limits, including the compatibility resolve command.

## Validation

Unit/contract tests cover byte budgets, missing/cyclic dependencies, constraints, prefix collisions, partial receipts, stdin, idempotency, timestamp-only changes and non-destructive launchers. CI also runs real skills CLI installation and fixed-transcript token comparisons using two named tiktoken encodings. Consult the release commit's Actions results for completed checks.

The benchmark is not live model evaluation or provider billing. No hooks, cloud permissions, semantic search, engine runtime certification or new runtime dependencies are introduced. Retain the v1 trusted-local-workspace deployment boundary. Re-run bootstrap after upgrading to install the short project launcher; existing records remain in place.
