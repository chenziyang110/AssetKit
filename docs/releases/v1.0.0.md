# AssetKit 1.0.0

Stable local-first asset workflows for coding agents. This release targets trusted local project workspaces and Git checkouts, not a hosted multi-tenant asset service.

## New workflows

- `capture PATH --use PURPOSE`: original-path registration, observable defaults, known sidecars, bounded explicit bundles, local glTF direct dependencies, idempotent unchanged calls and revision-checked updates.
- `find`: bounded active-asset summaries, scope/profile filters, a compact UTF-8 output budget and warm derived-index reads without opening the full card set.
- `resolve`: declared-file checks, purpose/rights/constraints and native reference hints; distinguishes inspection from authorized reuse and pointer files from verified payloads.
- `detect`, `scan`, `gate`, `doctor`, `backup`: profile evidence, dry-run/opt-in incremental inventory, omission/staleness checks, health diagnostics and non-overwriting metadata backup.
- JSONL batch capture, a per-call hash budget, configurable discovery roots/extensions/exclusions and structured operational errors.

## Project adapters

Unity, Unreal, Godot, Web, Android, iOS asset catalogs, Flutter, React Native, Electron, Tauri, ML and generic projects. Detection and native path hints are tested with synthetic fixtures. Full native engine dependency extraction and real engine/host execution are not claimed.

## Compatibility and operation

The schema stays at version 1 and existing IDs/source paths are preserved. The original low-level operations remain available. New capture records optionally include local stat signatures and observed source project context. Linked metadata/assets, obvious secrets and generated/tool-owned paths are now rejected more consistently. Read the runbook before upgrading a workspace that relied on those paths.

Each card write is atomic; a batch is per-asset, not all-or-nothing. Interrupted index updates are recovered from authoritative JSON records. Local locks do not serialize external editors, Git operations or multiple hosts. Git remains the normal cross-machine collaboration boundary.

## Verification

The repository contains backward-compatibility, concurrency, idempotency, crash-marker/index-recovery, budget, native-reference, bundle, Git inventory, safety and backup tests. CI runs the suite on Linux/Windows/macOS and Python 3.10/3.13, plus real skills CLI discovery/copy/symlink/global installation checks. See the release commit's Actions run for actual results, not just this description of the test matrix.

A reproducible 10,000-record synthetic benchmark is included in `docs/benchmarks/`; it is not a production SLA, media processing benchmark or guarantee about LLM token counts.

## Out of scope

Network-share SQLite, multi-host transactions, cloud storage integration, organizational authentication, automatic licensing decisions, semantic/vector search, media preview generation and guaranteed skill triggering by every host model.
